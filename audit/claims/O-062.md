# O-062 — definition: "top-10 %" is the mean of the highest tenth of token scores

**Source:** `docs/thesis/persona-coordinates-70b-results.md:141` (§2.4, "Pooling and aggregation").

**Claim as stated:** "Aggregating per-token scores (Goldowsky-Dill et al., 2025, and appendix
variants): score each token `s_t = ⟨h_t, w⟩`, then take the mean, the max, or the **top-10 %**
(the mean of the highest tenth of token scores)."

**Restated:** a definitional / methods claim. It asserts (a) per-token scores are a plain dot
product of the token's hidden state with a direction, and (b) the `top10pct` aggregation used
throughout §7.8 and §7.6 is the *mean of the top decile* of those scores, not the 90th percentile
and not the max.

## What I did

Read the definition out of the two scripts that produce every `top10pct` number in the document
(`14_pertoken.py` for the zero-shot half, `21_q8_trained_pertoken.py` for the trained half).
Printed by `audit/scripts/claims/W6A_transfer.py`.

```
O-062  top-10% definition, read from the producing code
14_pertoken.py:
def aggregate(scores: np.ndarray) -> dict:
    """Per-token scores -> one number per row, several ways. ..."""
    n = len(scores)
    k = max(1, int(round(0.1 * n)))
    srt = np.sort(scores)
    return {
        "mean": float(scores.mean()),
        "max": float(scores.max()),
        "last": float(scores[-1]),
        "first": float(scores[0]),
        "top10pct": float(srt[-k:].mean()),
        "last8": float(scores[-8:].mean()),
    }

21_q8_trained_pertoken.py:
def aggregate(s: np.ndarray) -> dict:
    """s: (n_tok, n_probes) -> {agg: (n_probes,)}"""
    k = max(1, int(round(0.1 * s.shape[0])))
    srt = np.sort(s, axis=0)
    return {"mean": s.mean(axis=0), "max": s.max(axis=0),
            "top10pct": srt[-k:].mean(axis=0), "last": s[-1]}
```

The per-token score itself: `14_pertoken.py:105-106` is
`d = unit(bank["axes"][args.axis][L].numpy())` then `s = seg[:, li, :] @ d`, i.e.
`s_t = ⟨h_t, ŵ⟩` — a dot product against a unit-normalised axis, as the doc says (the doc writes
`⟨h_t, w⟩` without saying `w` is normalised; that only rescales and cannot change an AUROC).

## Level 1 / Level 2

`top10pct = mean(sorted(scores)[-k:])` with `k = max(1, round(0.1·n))`. That is exactly "the
mean of the highest tenth of token scores". **Both scripts agree**, so the zero-shot and trained
halves of Q8 use the same definition and their numbers are comparable. `mean` and `max` are also
implemented as the doc describes.

One small imprecision, worth recording because it affects very short responses: `k` is
`round(0.1·n)` floored at 1, so for a response of **≤ 14 tokens** `top10pct` collapses to the
single maximum token, and for `harm-pressure-choice`'s 1-token responses it is identical to
`mean`, `max`, `last` and `first`. (Checked: `k` = 1 for n = 1…14, 2 for n = 15…24, 3 at n = 29.)
The doc does not say this. It matters for §7.8's per-dataset breakdown,
where `harm-pressure-choice` is the dataset token probes lose on most heavily.
