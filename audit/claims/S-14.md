`25_zeroshot_nulls.py:99–111`, the pooled statistic concatenates **every** `passB` dataset
with a `rows.jsonl` except `sycophancy_mt` — which at the time included the **2,000-row

`docs/thesis/...:935` does label the row "(incl. alpaca)" and the memory note gives 0.863
without it, so this is documented — but it is the reason the pooled figure and the per-dataset
