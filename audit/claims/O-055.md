and the file's own `significant_datasets` flag is **false**. F-67's audit note names this as the one
row of that entry that fails: it is marked "clears? YES" in the ledger while its own file says
otherwise.

So the honest form is: *the axis beats the matched random control in both blocks by ~+0.27, and that
margin survives BH only in the full block.*
