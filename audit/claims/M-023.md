## Verdict

**PARTLY HOLDS**

The byte count is right and the product is right: 6 x 64 x 1869^2 x 4 = **5,365,495,296 bytes**, product 11,214 = 6 x 1869. But **the unit on this row is wrong**: 5,365,495,296 B is 5.365 **GB** and **4.997 GiB**. The note labels it "5.36 GiB". The CUDA message quoted on the same line — "Tried to allocate 5.00 GiB" — is the correct GiB value, so the note contradicts itself within one line.

## Notes for the lead

This is the only unit slip in the table: the other three rows (2.15, 0.61, 4.30) and the later ai_audit figures (4.2-13.6 GiB for T = 4,211-7,543) are all correct in GiB, which I reproduced. Consequence if uncorrected: anyone calibrating `--attn_budget_gib` from this row sets a budget ~7% too high. Suggested fix: "attn 5.00 GiB".
