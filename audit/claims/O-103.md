# O-103 - the chain's own verdict block ("3b separability ... stripped=0.947 ... GATE FAILED")

**Claim (restated).** `docs/thesis/sarcasm-pilot-negative-result.md:199-204` presents a verbatim
block as "The pilot's own chain reports", with `3b separability measured=bag-of-words AUROC
stripped=0.947 predicted=<=0.65 GATE FAILED` and `VERDICT TEACHER-FORCED ... separable (0.947)`.
Section 5 then says the chain "has since been corrected and now reaches it independently".

**What I did.** Compared the quoted block against every preserved version of the chain's status
file, from batch P7's read-only dump of the lab `logs/`
(`audit/phase2/out/P7_status_files.txt`, md5 e6f6a80ecaac9b9bdd66952fa2de3115).

```
########## sarc_pilot.status  (2026-09-22 15:55)        <- THE CURRENT ONE
  3a markers  measured=lowest ironic marker rate=0.00  predicted=<=0.20  PASS
  3b separability  measured=bag-of-words AUROC on unmarked(v4,v5), markers stripped=0.921
                   predicted=<=0.65  GATE FAILED
    raw=0.953 stripped=0.947 marker effect=0.005
  VERDICT TEACHER-FORCED -- markers are suppressed but the arms remain lexically separable (0.921)

########## sarc_pilot.status.2026-09-21-buggy-verdict  (2026-09-21 21:45)
  3 markers  measured=lowest ironic marker rate=0.00  predicted=<=0.20 to proceed on-policy  PASS
  VERDICT PRODUCIBLE -- build the factorial on that variant
  lexical separability ironic vs sycophant: raw=0.953 stripped=0.947 marker effect=0.005

########## sarc_pilot.status.pre-e2e-2026-09-22  (2026-09-22 02:29)   <- WHAT THE DOC QUOTES
  3a markers  measured=lowest ironic marker rate=0.00  predicted=<=0.20  PASS
  3b separability  measured=bag-of-words AUROC, markers stripped=0.947  predicted=<=0.65  GATE FAILED
  VERDICT TEACHER-FORCED -- markers are suppressed but the arms remain lexically separable (0.947)
```

**Finding.** The quoted block is verbatim from the **superseded 02:29 run** of 2026-09-22, not from
the chain as it stands. The current chain gates on the **unmarked v4+v5 subset** and reports
**0.921**, not 0.947. Both numbers are correct measurements of different subsets (both reproduced
in O-098 and O-100), and both fail the 0.65 bar, so the verdict is identical either way. But the
document's own section 3.2 quotes **0.921** at `:121` while section 5 presents **0.947** as what
"the chain reports", and a reader comparing the two will see two different decisive numbers with no
explanation.

**The process note in section 5 checks out.** The 09-21 21:45 file does log `VERDICT PRODUCIBLE`
with `stripped=0.947` on the next line, exactly as described; the 3b gate line is absent from it
altogether. F-104's "the fix never reached the machine until 09-22" is consistent with the 02:29
file being the first to carry a 3b gate.

**Related (O-097).** The 0.65 the block tests against was written into the chain at 21:48:54 on
09-21, after the 21:44:27 print of 0.947 - so the gate this block reports "failing" was
operationalised after the number it judges.

**Version.** Status text from batch P7's read-only lab dump; the chain script is
`cap/scripts/run_sarc_pilot.ps1` (RF-14: its DONE guard can never fire, so every trigger truncates
and rewrites this .status file - which is why only three snapshots survive).

**Verdict: PARTLY HOLDS.** The block is a faithful quote of a real chain run, but of a superseded
one; the chain's current verdict line reports 0.921. Confidence HIGH. Importance MEDIUM - the
conclusion is unchanged, the document is internally inconsistent about which number is decisive.
