## Level 1 / Level 2

All ten values match to 5×10⁻⁴. The surrounding counts also check out: "above 0.5 on **9 of the
10** datasets the length control was run on", "`roleplaying` (0.441) is the sole inversion", and
"that set keeps `sycophancy_mt` and drops `harm-pressure-kr-matched`" — the file's dataset list
has 11 entries, none of which is `harm-pressure-kr-matched`, and 10 get a length AUROC (alpaca
is single-class). **The audit's DF-49 edit is correct on every number it states.**

## Three problems with the edit itself (for DOC_FIXES, not verdict-changing)

1. **The path does not exist in the repo.** `run-coords/confounds_L44_last.json` is **not** in
   the git working tree — `run-coords/` holds 37 entries and this is not one of them. The file
   exists only on the lab PC (and now in `audit/cache/labpc/run-coords/`). A reader following
   the citation finds nothing. The tag "(log only)" was wrong, but "stored in
   `run-coords/…`" is wrong too for anyone reading the repo.
2. **The key is nested and differently named.** It is `confounds.length_only_auroc`, and it is a
   *list of records* whose value field is `auroc_from_length` — not a mapping named
   `length_only_auroc` at the top level.
3. **The edit contradicts the sentence two lines below it, which was left in place.** The doc
   still says "Only the sycophancy value (0.664) is also in a result file". After the edit,
   *all ten* values are in a result file — the one the edit itself names. One of the two
   sentences has to go.

## Bonus (relevant to DF-49's other half)

The same file carries `median_pos` / `median_neg` token counts. By **median** gap the deceptive
class is longer in 8 of these 10 datasets, tied in 1 (`harm-pressure-choice`, both 1 token) and
shorter in 1. The doc's "9 of 11 by **mean** token gap (8 of 10 excluding `sycophancy_mt`)" is a
different metric over a different (11-dataset, kd11) set and is not testable from this file —
which is exactly why the edit's own warning ("the two counts are different metrics over
different sets; always say which") is the right correction.
