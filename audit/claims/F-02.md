# F-02 — "HP-KR cannot attribute its own results"

**Source:** `kd/docs/FINDINGS.md:35` (status in doc: *verified*). Batch P1-hpkr.
**Importance:** HIGH — this is the diagnosis the whole `kd/` experiment is built on, and the
memory note "HP-KR cannot attribute itself" repeats it.

## The claim, stated precisely
With `deceptive = knows AND denies` and `knows = (model_belief != -1)`, the cell counts over
the **7,068** rows of `results/subsets/harm-pressure-knowledge-report.csv` are:

| knows | denies | deceptive | n (doc) |
|---|---|---|---:|
| False | True | honest | 1,199 |
| True | False | honest | 4,405 |
| True | True | deceptive | 1,339 |
| False | False | deceptive | **0** |

and two consequences are asserted:
(a) on the text-matched slice (`denies=True`), `deceptive ⟺ knows` **exactly**, so a pure
knowledge probe scores **1.0**;
(b) within `knows=True`, `deceptive ⟺ denies`, so a pure lexical probe scores **1.0**.

## What I did
Same script as F-01: `audit/scripts/claims/F-01_F-02_F-16.py` (cell counts) plus an inline
follow-up that computes the two implied AUROCs directly. Both read the CSV; `denies` is the
transcribed regex, `knows` is `meta['model_belief'] != -1`.

## Level 2 — where it breaks
The table **looks like a partition of the dataset and is not**. Two non-empty cells are
missing from it:

| knows | denies | label | n | in the doc's table? |
|---|---|---|---:|---|
| False | False | **honest** | **57** | no |
| True | False | **deceptive** | **68** | no |

The four listed cells sum to **6,943**; the CSV has **7,068** rows. The 125 missing rows
(1.8%) are exactly the ones that break the clean story.

Consequences for the two asserted implications:

- **(a) holds exactly.** Restricted to `denies=True` (2,538 rows over all models, 258 on the
  Llama rows) there is no honest-and-knowing row and no deceptive-and-not-knowing row, so the
  knowledge feature scores **AUROC 1.0000** — verified, not assumed.
- **(b) does not hold exactly.** Restricted to `knows=True` there are **68** deceptive rows
  (15 on the Llama rows) whose response does *not* match the denial regex. The lexical
  feature therefore scores **0.9758** over all rows and **0.9460** on the Llama rows — high,
  but not the **1.0** the entry states.

The 68 are the same rows F-01's caveat calls "68 deceptive rows it does not catch"; the entry
records them one paragraph earlier and then writes a table that has no place for them.

Note this does not rescue HP-KR: 0.946–0.976 is still close enough to 1.0 that knowledge,
wording and deception remain practically inseparable in this dataset. The *direction* of
F-02 stands; its "exactly" and "1.0" do not.

## Robustness
The Llama-only equivalents (which are the rows the probe pipeline actually reads, F-16) are
57→4, 1,199→134, 68→15, 4,405→1,862, 1,339→124. The pattern is identical: the fourth cell is
empty, cell (T,F) is mixed. The doc flags the all-rows/Llama-rows distinction in its own
source line.

## Verdict
**PARTLY HOLDS** — confidence **HIGH**.
All four quoted counts reproduce exactly and the "fourth cell is empty" claim is correct.
But the table omits two non-empty cells (57 and 68 rows), so it is not the partition it
appears to be, and the statement "within `knows=True` a pure lexical probe scores 1.0" is
false: the measured value is 0.976 (all rows) / 0.946 (Llama rows).
