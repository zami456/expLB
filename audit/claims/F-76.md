## The "37/80 (46%)" cross-reference — this is where the doc-internal conflict lives
F-77 and F-81 quote this same kd slice as **"37/80 (46%)"** layers positive. That number is
**not an observed layer count**. The observed counts are **28/80** (vs raw) and **31/80**
(vs `datapca`) — F-75's figures, which I reproduce above. **0.46 is F-76's bootstrap median
*fraction*** (measured 0.4625); 0.4625 × 80 = 37.0. So "37/80" is a bootstrap median fraction
converted into a layer count and presented beside a real layer count (the cap bank's 21/21).
**F-75 is right and F-77/F-81's comparison cell is wrong.** Details in `audit/claims/F-77.md`.
