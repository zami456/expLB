## Findings

**(a) — VERIFIED.** Same rollouts, judge the only variable: 91.185 % exact agreement, 0.74 pp
score-3 gap. The caveat is that "interchangeable" holds at the level of *rates*: the two judges keep
8.15 % different **sets** of rollouts (110 of 1,350).

**(b) — the mechanism is VERIFIED; the magnitude is DEFERRED.**
- *The confound is real and documented in the thesis itself.* Line 267: `own100` = "our 100-role
  persona bank … built on AA's 240 questions, ~1,200 rollouts per role, judged by Llama-3.1-70B".
  Line 268: `hf275` = "Lu et al.'s **published vectors** … judged by gpt-4.1-mini". So the two banks
  differ in role set, question bank, rollout count **and** judge. A difference between them cannot be
  attributed to the judge. That is exactly what the sentence says.
- *The hf275 half of the earlier table is exactly right.* Measured from the local vectors,
  cos(deception contrast, published Assistant Axis) = −0.6856 / −0.6621 / −0.6097 / −0.5161 at
  L20/22/40/60, against the memory note's −0.686 / −0.662 / −0.610 / −0.516 — max |diff| 0.0004.
- *The own100 half cannot be checked here.* `C:/Users/user4/expLB/run/axes.pt` is lab-only and the
  lab PC is unreachable (`audit/PROGRESS.md` incident section). **DEFERRED (lab unreachable)** —
  the file needed is `C:/Users/user4/expLB/run/axes.pt`.
- *Taking the memory note's own100 column as given*, the relative gap is **5.9 % – 9.9 %**, not
  7–9 %: 5.9 % at L20, 6.8 % at L22, 7.6 % at L40, 9.9 % at L60. The thesis's "~7–9 %" is the middle
  of that spread.
- The "~7–9 %" figure exists only in prose (`memory/persona-axis-diagnostics.md:50`, DOC-ONLY); no
  result file in the repo holds an own100-vs-hf275 contamination comparison.
- One inherited slip, the same one W6A found in O-057/O-067: the hf275 numbers are measured against
  the **published** Assistant Axis. Against the hf bank's **own** assistant direction they read
  −0.6687 / −0.6507 / −0.5771 / −0.4787, which would move the implied gap.

## Verdict — **PARTLY HOLDS**
The verdict "judges are interchangeable here" is verified on the data it is about. The diagnosis of
the earlier gap as a judge/generation confound is verified from the document's own pipeline
description. The **magnitude** "~7–9 %" is not verifiable from local data — its own100 term is
lab-only — and the note it comes from implies 5.9 %–9.9 %.

**Confidence:** HIGH for part (a) and for the confound argument; LOW-MEDIUM for the "~7–9 %" number
(DOC-ONLY, one term DEFERRED).
**Importance:** MEDIUM-HIGH — it is the sentence that retires a whole earlier line of "judge
sensitivity" reasoning; if the number is kept it should be sourced or dropped.

**For the reframed thesis:** either drop the "~7–9 %" (the sentence works without it — the confound
is the point), or state it as "5.9–9.9 % across layers 20–60, own100 vs hf275, both measured against
the published Assistant Axis", and say that the own100 vectors live only on the lab machine.
