**A caveat the row invites.** At n = 40 with 20 leave-one-question-out folds, an AUROC of exactly
1.000 means every ironic response outranks every sycophantic one; it is a ceiling, so "1.000" should
not be read as a precise effect size. Note also that the v1 **sycophantic** arm is 0.85 marked too,
so v1's perfect separation is not attributable to irony markers alone.
