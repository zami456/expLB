## Verdict — PARTLY HOLDS
Two of the four figure descriptions are right (fig1 and fig4, both explicitly hardcoded), the fig2
number is right, and `fig_data.json` is byte-exact. Two statements fail:

1. **"the dataset-level CI band spanning zero at every layer"** is false at L40 and L44 — the two
   layers the project quotes most. The defensible version of the same point is *"no layer clears the
   BH-corrected threshold"* (best q = 0.127 in the 09-20 test family, 0.100 in the current one), which
   is what the figure's own annotation says and what F-34 means. As written, the entry overstates the
   null result. This matters because the sentence is offered as "the honest part of the figure".
2. **The fig3 described does not exist.** Every surviving artefact — the committed script (both
   commits), and the PNG/PDF on disk — plots F-63's corrected three-rung comparison
   (raw 0.762/0.798/0.809; +0.020/+0.013/+0.013 vs raw; +0.202/+0.115/+0.079 vs dataset PCA). The
   figure F-57 describes was presumably replaced the next day when F-63 corrected F-58/F-39, and the
   ledger entry was never updated. Nothing is wrong with the current figure; the ledger text is stale.

21-layer kd_s23 bootstrap in that reduced form** — but I verified that the regenerated lab file
