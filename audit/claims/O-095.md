## The claim, restated
Of the paper16 persona rollouts, the original Llama-3.1-70B judge scores **80.7 %** at the top grade
(3 = "fully in persona") and the Llama-3.1-405B re-judge scores **79.9 %** — a gap of **0.8
percentage points**. Score 3 is the filter that selects which rollouts build the persona vectors.

## What I did
`audit/scripts/claims/W6B_q5q7.py` recomputes everything from the two raw judge stores —
`run-paper16/scores/*.json` (70B) and `run-paper16/scores_405b/*.json` (405B) — pairing on
(persona, item key). **There is no result file for Q7**: no script in the repo aggregates these two
stores, so this is a Level-2-only recomputation from raw output.

## The second half — "this is the filter that builds the vectors"
Verified in code by the sibling claim M-015: `src/assistant_axis_ndif/2_activations_ndif.py:20-21`
states `"Kept" = judge score == 3 (--keep_scores), except 'default' where all responses are used`,
with `--keep_scores` defaulting to `"3"`. I did not re-open that file; I cite M-015.

**A number neither the document nor M-015 reports:** the two judges keep *near-identical numbers* of
rollouts (1,089 vs 1,079) but **disagree about which ones** on 110 of 1,350 items — a **8.15 %**
symmetric difference, intersection 1,029. For a sentence whose point is "score 3 is the filter that
builds the vectors", 8.15 % of the training set changing is the relevant quantity, not 0.74 pp.

## A separate defect on the same claim's evidence line
§7.7's "Measured" line (`:752`) says "**all 1,400** paper16 rollouts re-judged". Only **1,350** were:
`run-paper16/responses/` holds 1,400 records across 26 files, and the 26th, `default.jsonl` (50
rollouts, the anchor persona), has **no score file in either store** — by design, since the anchor is
never filtered. The document contradicts itself: line 390 already says "1,089 of 1,350 judged
rollouts (80.7 %); the default persona is not judged."

## Verdict — **HOLDS**
Both rates and both full score distributions reproduce exactly from the raw stores; the "0.8 pp" is
the difference of the rounded rates (exact value 0.74 pp).

**Confidence:** HIGH — 1,350 paired items recomputed from the raw judge output, independently of the
sibling batch W5D, and agreeing with it to the digit.
**Importance:** MEDIUM — this is what closed Q7 and stopped further judge ablations; it also licenses
comparing banks judged by different models.

**For the thesis:** print "0.74 pp" (or "0.7 pp"), fix "all 1,400" to "1,350 (the `default` anchor is
not judged)", and add the 8.15 % symmetric difference — otherwise the sentence claims more
interchangeability than the data shows.
