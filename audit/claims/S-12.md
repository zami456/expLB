**One near-miss.** The review quotes the dataset-level 95% interval as **[−0.22, +0.17]**;
`run-crossgen/significance.json` records `pc:unified@2 − raw` dataset_ci95 =
**[−0.2308, +0.1789]** (10,000 dataset bootstrap draws), which is also what the memory note
`matched-control-kills-the-gain.md` records ([−0.231, +0.179]). The review's figure is either
rounded loosely or from an earlier bootstrap draw; nothing turns on it — the interval
straddles zero either way. Recorded as a discrepancy, not a failure.
